## 🚀 Projeto em destaque

### Capitu.ia — Chatbot inteligente para descoberta bibliográfica

Projeto acadêmico desenvolvido em equipe para facilitar a descoberta de obras bibliográficas por meio de uma interface conversacional em português.

A proposta combina processamento de texto, TF-IDF, similaridade textual e regras de interpretação de intenções, com consulta ao Open Library para apresentar referências bibliográficas.

**Minha contribuição:**
- Atuação na interface de usuário existente.
- Organização de dados e materiais do projeto.
- Participação nas etapas de integração, validação e ajustes da solução.

**Tecnologias:** Python, TF-IDF e Open Library.
